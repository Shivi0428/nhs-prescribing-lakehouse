# Power BI dashboard

Power BI reports are binary `.pbix` files and need Power BI Desktop, so the
report itself isn't generated by this repo. This folder holds what you need to
build it in about twenty minutes from the gold tables.

## Connect

Gold tables are Delta. Pick whichever fits your setup:

- **Azure**: Get data → Azure Data Lake Storage Gen2 → point at `lake/gold`, or use the
  Databricks connector with a SQL warehouse.
- **Local**: export gold to Parquet and load the folder:
  ```python
  spark.read.format("delta").load("data/lake/gold/fact_prescribing") \
       .write.mode("overwrite").parquet("data/export/fact_prescribing")
  ```

## Model

Relationships (all many-to-one, single direction, from the fact):

| fact_prescribing | dimension       |
|------------------|-----------------|
| `date_key`       | `dim_date`      |
| `practice_key`   | `dim_practice`  |
| `drug_key`       | `dim_drug`      |
| `icb_key`        | `dim_icb`       |

Mark `dim_date[month_start]` as the date column.

## Measures

```DAX
Total Cost      = SUM ( fact_prescribing[actual_cost] )
Total Items     = SUM ( fact_prescribing[items] )
Cost per Item   = DIVIDE ( [Total Cost], [Total Items] )
Cost YoY %      =
VAR prev = CALCULATE ( [Total Cost], SAMEPERIODLASTYEAR ( dim_date[month_start] ) )
RETURN DIVIDE ( [Total Cost] - prev, prev )
```

## Suggested pages

1. **Overview**: cards (cost, items, cost per item), monthly trend line, financial-year slicer.
2. **Therapeutic areas**: cost by `dim_drug[bnf_chapter_name]`, top 15 chemical substances.
3. **Geography**: cost per ICB (use `agg_icb_chapter_month` for speed), ICB slicer.
4. **Practices**: top practices by cost, with a drill-through to a single practice.
